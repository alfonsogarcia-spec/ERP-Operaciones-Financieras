2 · Botón

Una acción principal por pantalla. Destructivo = contorno rojo; estado = relleno.

Variantes

Tamaño y estados

HacerVerbo concreto: “Enviar correo”, “Liberar contracargo”. El diálogo de confirmación repite el verbo.
EvitarEstilos en línea con hex (background:#0F56AC). Usa .btn.deep u otra variante.

3 · Badge y pill

Un solo componente; el tono se nombra por significado, no por letra. Texto siempre con ≥4.5:1.

5b · Zona de archivos

Todas las cargas del sistema usan el mismo componente (zonaArchivos()): se arrastra el archivo o se hace clic. Solo acepta las extensiones indicadas, también al soltar.

Normal

Arrastra aquí el Excel o CSV
.xlsx, .xls o .csv · o haz clic para elegirlo

Compacta (dentro de un panel)

Arrastra la evidencia aquí o haz clic
PDF, imágenes, Excel, Word, CSV o ZIP · máx. 15 MB
comprobante.pdf84 KB
HacerUsar zonaArchivos({accept, multiple, onFiles}); leer zona.input.files como siempre.
EvitarUn <input type="file"> suelto: no se puede arrastrar y se ve distinto en cada pantalla.

5c · Filtro de fechas

Todos los filtros de fechas del sistema usan el mismo componente (filtroFechas()): un solo campo que abre un calendario con atajos. Los campos de fecha de captura en formularios no cambian.

Rango

Vacío (todas las fechas)

Un día

HacerUsar filtroFechas({desde, hasta, onChange}) o leer f.desde.value / f.hasta.value como antes; modo:'dia' para un solo día; permiteVacio:false si el reporte exige periodo.
EvitarDos <input type="date"> sueltos como filtro: ocupan el doble, no tienen atajos y se ven distinto en cada navegador.
